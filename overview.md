# Aging WIP

Each dot is an open work item. The horizontal axis shows how old the item is (days since it was created), the vertical axis how many days it has spent in its current state.

- Dots near the dashed diagonal have not changed state since they were created.
- Dots above the red line have been in the same state for longer than the chosen threshold (a year by default).
- Hover a dot for details, click it to open the work item.

Available as a hub under **Boards → Aging WIP** and as a dashboard widget.
