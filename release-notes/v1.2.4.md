## Clearer labels

Two measures run through Aging WIP: **days since work started** (how long ago work on an item began) and **days in the current state** (how long it has not moved). The labels now always say which one a number is.

### Changed

- **Report tiles** are grouped under *Days since work started* (median, 85th percentile, started longest ago) and *Days in the current state* (over threshold, changed state in the last 30 days).
- **"Oldest item" is now "Started longest ago"** and also shows its days in state. Before, it could look as if it was missing from the "Longest in the current state" list, which is sorted by days in state.
- **Report tables**: *By state · days in the current state* (median, 85th pct., longest), and *Since start* instead of *Age* in the item list.
- **Hub and widget**: the X axis reads *days since work started*, tooltips show *Since start* / *In state*, the item table has *Days in state* / *Days since start*, and the hub subtitle explains both axes.
