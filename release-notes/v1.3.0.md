## Threshold counts days since work started

### Changed

- **The threshold now counts days since work started.** Before, it counted days in the current state. The red line on the chart is now vertical ("1 year since work started"). The hub summary, the widget and the "Over threshold" tile now say how many items started more than the threshold ago. In the downloadable report, that tile sits under "Days since work started".
- **The item list puts the oldest work first.** The hub table and the report table are now called "Started longest ago". They are sorted by days since work started, and the "Days since start" column comes before "Days in state".
- **Each chart axis follows its own data.** The "days since work started" axis shows at least 60 days and the "days in current state" axis at least 30. With larger values, each axis grows to fit the data, so a team with young work no longer sees all its dots squeezed into one corner. The threshold no longer stretches the axis: when every item is younger than the threshold, the red line is not shown.
