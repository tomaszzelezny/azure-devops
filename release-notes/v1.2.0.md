## Focus on forgotten work

Usage testing showed that items in the current sprint get in the way when you look for aging work: they are being worked on right now and the team already sees them on the sprint board. What deserves attention is the work nobody is looking at any more. This release lets you leave the sprint out and see where each item is planned.

### New

- **Include current iteration** filter (hub and widget configuration). It is on by default, so nothing changes until you uncheck it. Unchecked, the chart, legend counts and item list leave out every item under the team's current iteration, including its child iterations. For **Entire project** it uses the current iteration of the project's default team.
- **Iteration path** column in the item list under the chart, so you can see at a glance which items sit in old iterations or in the backlog.

### Changed

- The new filter sits in the first row next to **Threshold line**, so the filter area is no taller than before.
