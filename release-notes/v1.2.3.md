## Clearer numbers

### Changed

- **Report, "By state" table**: the median, 85th percentile and maximum now count only the **days in the current state**. Before, the median and P85 used the age since work started, which mixed two different measures in one table. The columns are now *Median in state*, *P85 in state* and *Max in state*. The summary tiles at the top still describe the whole lifecycle (age since work started).
- **Hub item list**: the *Assigned to* column is gone, so the table focuses on how long work has been waiting and where it is planned.
