## More reliable loading

### Fixed

- **The hub no longer loads forever.** After a filter change it could stop at "Reading work item history… 141 / 142" until the page was reloaded. Every Azure DevOps request now gives up after 30 seconds and is tried again, up to three times. A filter change also cancels the load that is still running.
- **No more "Unexpected token '<', "<!DOCTYPE "... is not valid JSON".** Sometimes Azure DevOps answers with a web page instead of data, for example the sign-in page while the process is being changed. Aging WIP now tries again with a fresh sign-in, and if that does not help it says so in plain words.

### Added

- **Reload page button.** If loading makes no progress for 45 seconds, or fails, the hub says so and offers a button that reloads the page.
- **Refresh picks up process changes.** Refresh, and the first load after an error, read the work item types again, so a type disabled in the process settings disappears without reloading the page.
