# Privacy policy – Aging WIP for Azure DevOps

Last updated: 2026-10-05

Aging WIP runs entirely in your browser, inside Azure DevOps.

- **What it reads.** Work item types, teams, work items and their update history in the current project, through the Azure DevOps REST API with the signed-in user's own permissions (scopes `vso.work` and `vso.project`). It never writes to Azure DevOps.
- **What it stores.** Hub filter choices are saved in your browser's local storage. Widget settings are saved by Azure DevOps in the dashboard, like any other widget's settings.
- **What it sends elsewhere.** Nothing. The extension has no backend, no analytics or telemetry, and makes no requests to any service other than your Azure DevOps organization.
- **Cookies and tracking.** None.

Questions: open an issue at <https://github.com/tomaszzelezny/azure-devops/issues>.
